  # OTTO

  **O**ptimization for **T**rucking and **T**ransport **O**perations

  Open-source logistics optimization platform. Route planning, fuel cost minimization, Hours of Service compliance, fleet
  scheduling, and custom map rendering.

  ## Status

  🚧 **Coming soon** — Code will be published here when ready for public release.

  ## What's Inside

  | Engine | Purpose |
  |--------|---------|
  | **Ralph** | LP/MIP solver |
  | **Velo** | OSM routing |
  | **Carta** | Map tile generation |
  | **Locus** | Geocoding |
  | **FuelWise** | Refueling optimization |
  | **ClayShards** | Immediate-mode UI |

  ## Design Principles

  - **Zero dependencies** — Vendor libraries are vendored source
  - **WASM-first** — Same code runs in browsers and on servers
  - **MIT licensed** — Core engines are open source
